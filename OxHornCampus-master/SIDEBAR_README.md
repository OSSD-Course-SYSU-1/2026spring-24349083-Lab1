# 侧边栏功能使用说明

## 功能概述

为 OxHornCampus 应用添加了一个侧边栏功能，用户可以通过侧边栏快速选择不同的分区（A区、B区、C区等），实现快速导航。

## 新增文件

### 1. SideBarComponent.ets
**位置**: `entry/src/main/ets/view/SideBarComponent.ets`

**功能**:
- 侧边栏主组件，显示所有分区列表
- 支持分区选择和切换
- 提供关闭按钮和遮罩层

**主要特性**:
- 显示13个分区（A-M）的列表
- 每个分区项显示：分区标识、标题、副标题
- 当前选中分区有高亮显示和勾选标记
- 点击分区项后自动关闭侧边栏
- 点击遮罩层可关闭侧边栏

## 修改文件

### 1. MainPage.ets
**位置**: `entry/src/main/ets/pages/MainPage.ets`

**修改内容**:
- 导入 SideBar 组件
- 添加状态变量：
  - `isSideBarOpen`: 控制侧边栏的显示/隐藏
  - `selectedZoneIndex`: 记录当前选中的分区索引
- 添加悬浮按钮（左上角），点击打开侧边栏
- 集成侧边栏组件，支持动画过渡效果

### 2. ZonesComponent.ets
**位置**: `entry/src/main/ets/view/ZonesComponent.ets`

**修改内容**:
- 添加 `selectedZoneIndex` 状态监听
- 实现 `aboutToAppear` 生命周期方法，初始化时同步选中分区
- 添加 `onSelectedZoneChange` 监听方法，当侧边栏选择分区时自动滚动到对应位置

## 使用方法

### 打开侧边栏
1. 在应用主界面左上角，点击蓝色的圆形按钮（显示☰图标）
2. 侧边栏将从左侧滑出

### 选择分区
1. 在侧边栏中查看所有分区列表
2. 点击想要查看的分区（如"A区 Oxford"）
3. 侧边栏自动关闭
4. 应用自动切换到"区域导览"标签页
5. 卡片列表自动滚动到选中的分区

### 关闭侧边栏
- 点击右上角的"×"按钮
- 点击侧边栏外的遮罩区域
- 选择一个分区后自动关闭

## 技术实现

### 状态管理
- 使用 `@State` 管理侧边栏的打开状态
- 使用 `@StorageLink` 在组件间共享选中的分区索引
- 使用 `@Watch` 监听分区选择变化

### 动画效果
- 侧边栏滑入/滑出动画（300ms）
- 悬浮按钮的显示/隐藏过渡
- 分区切换时的平滑滚动动画

### UI设计
- 侧边栏宽度：280px
- 分区列表项高度：70px
- 主题色：#4A90E2（蓝色）
- 支持阴影和圆角效果

## 注意事项

1. 侧边栏功能仅在主页面可用
2. 选择分区后会自动切换到"区域导览"标签页
3. 分区索引从0开始（A区=0, B区=1, ...）
4. 状态通过 AppStorage 在全局共享，支持跨页面保持选中状态

## 兼容性

- 支持 HarmonyOS 5.0.5 及以上版本
- 支持手机、平板、2合1设备
- 与现有功能完全兼容，不影响原有交互逻辑
